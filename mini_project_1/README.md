# Mini Project 1: Hysteretic Oscillator

The goal of this project is to design a circuit and PCB to blink an LED at 1Hz +/- 10% using a hysteretic oscillator implemented with an op-amp. The project includes simulation and worst-case analysis to verify the behavior of the circuit.

## File Structure
- KiCad files are in this directory along with symbol/model imports
- Simulations are located in `simulation`. Nominal simulation is titled `mini_project_1.asc` while worst-case sim is titled `mini_project_1_worst_case.asc`
- The report is located in the `report` directory and is titled `report.pdf`
